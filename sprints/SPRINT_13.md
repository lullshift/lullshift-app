# Sprint 13 - Fresh content from your own model

**Status:** Closed 2026-11-08 (everything the owner can't check by hand is done; see Closeout).

**Goal:** Users who set up a Companion model can ask it for a fresh set of questions, teasers, cards, prompts or typing lines, with consent, and play it in the unchanged, sandboxed engine. Behind a second opt-in, the model can also write movement, breathing and pause routines under strict host rules. Every set is clearly labelled as AI-generated. Packs with many items show a different round each time, with no model needed.

**Depends on:** Sprint 12 (Companion streaming and per-message model choice, the `jsonschema` pack check, pack text checks). ADR-028 accepted.

- [ ] S13-A02 (automated part done against a loopback fake provider; the live-provider run is manual check M13-02): With a working provider, a quiz set is written, checked, saved, played, paused, resumed after an app restart, and replayed offline.

## Guardrails

- The activity sandbox, CSP, bridge and permissions don't change. Engines never get network or IPC.
- Network use only on the user's button press; no background or pre-emptive generation.
- Generation profiles are host code; nothing from a marketplace reaches the prompt.
- Model-written text is untrusted: checked like third-party pack data, rendered as text only.
- Keys stay in the OS keychain; topics and set contents are never logged.
- Movement, breathing and pause routines only behind their own switch, with host-owned timings and safety text; the refused-phrase check is never loosened to let a set through.
- Every model-written set is labelled AI-generated wherever it appears.
