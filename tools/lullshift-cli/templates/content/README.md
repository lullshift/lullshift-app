# {{name}}

A Lullshift content pack for the `{{engine}}` engine, started from the `content` template.

It holds data only: no HTML, JavaScript or CSS. `lullshift validate .` checks `deck.json` against
the engine's data schema, and `lullshift simulate .` runs it in the engine. Add `help` and a
`preview` image to `manifest.json` so players know what it is.
