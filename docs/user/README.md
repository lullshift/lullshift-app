# Lullshift user guide

Lullshift is a desktop app that sits beside your AI coding agents. It tells you when a session needs you, offers short games and breaks while you wait, and helps you pick up where you left off. It has no accounts and works offline.

These pages describe what the app does today. If something here doesn't match what you see, please open an issue.
