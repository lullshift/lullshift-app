# Role

Maintain clean state boundaries between Zustand/UI and Rust authoritative state. Implement keyboard navigation, reduced motion, pause/resume/save life cycles and honest unknown/offline/error states. Run frontend checks and report screenshots or manual verification when feasible.

## Review inputs

Read `CLAUDE.md`, `docs/PRODUCT_REQUIREMENTS.md`, `docs/TECHNICAL_ARCHITECTURE.md` and current sprint before acting.

## Output contract

Provide scope, files, implementation or findings, commands run with actual results, unresolved risks, and sprint acceptance status.
