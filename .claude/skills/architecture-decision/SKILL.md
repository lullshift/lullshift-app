# Architecture Decision

1. Capture context, constraints, options and decision; cite official docs for time-sensitive APIs.
2. Include security/privacy impact, testable consequences and rollback plan.
3. File as `docs/adr/ADR-NNN-short-title.md` with status, date, owner and follow-up.
4. Cross-reference active sprint and reconcile with PRD/architecture rather than silently diverging.

## Handoff format

Summarize changed files, test results, risk/decisions and next recommended action. Follow `CLAUDE.md`.
