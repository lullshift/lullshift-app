# Sprint Delivery

1. Read `sprints/ROADMAP.md`, active `sprints/SPRINT_XX.md`, `CLAUDE.md`, PRD and architecture.
2. Enumerate acceptance criteria and dependencies; identify external credentials and platform blockers.
3. Implement the smallest vertical slices; commit by behavior, not file grouping.
4. Delegate security/architecture reviews as relevant; execute real tests, collect outputs.
5. Mark only demonstrated criteria done; produce sprint summary with files, commands, failures, next risks.
6. Do not implement future sprints without approval.

## Handoff format

Summarize changed files, test results, risk/decisions and next recommended action. Follow `CLAUDE.md`.
