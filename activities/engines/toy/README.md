# Creative Toy

An engine (`lullshift.toy@1`) for calm, generative drawing toys. A toy pack supplies a title, a palette of two to eight named colours, a style of mark (ripples, mosaic, stars or threads), an optional symmetry (none, mirror, quad or radial6), a brush size range and a background colour.

Play with the keyboard (arrows, Space, number keys) or the mouse. The canvas keeps up to 2000 marks and saves them exactly. Reduced motion turns off the gentle grow-in of new marks. There is no export, no network and no file access.

Original code and art, licensed Apache-2.0. Packs live in `activities/content/toy/`.
