# Guided Pause

Engine `lullshift.pause@1`. A short run of timed text steps, each with an optional small picture, a gentle progress bar, and skip and back. Original code, licensed Apache-2.0.

- Data: see `data.schema.json` (title, intro, steps with text, seconds and an optional look, closing).
- Packs live in `activities/content/pause/`.
- Without a pack it shows a small built-in sample.
- Time stops when the host pauses; the saved state is the exact step and position.
