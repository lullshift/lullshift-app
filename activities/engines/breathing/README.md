# Breathing Space

Engine `lullshift.breathing@1`. A soft shape grows and shrinks with a breathing pattern from a content pack. Original code, licensed Apache-2.0.

- Data: see `data.schema.json` (title, intro, phases, rounds, closing). Holds are at most 4 seconds.
- Packs live in `activities/content/breathing/`.
- Without a pack it shows a small built-in sample.
- Time stops when the host pauses; the saved state is the exact position.
