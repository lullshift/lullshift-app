# Shapes and Sides

Eight picture questions about flat shapes: their sides, corners and names. A content pack for the Quick Quiz engine (`lullshift.quiz@1`): 8 items in `quiz.json`, eight pictures in `images/`, no code.

The first bundled pack with pictures (ADR-016, Sprint 12). Each picture is listed in the manifest's `images`, and each question names its picture with alt text that gives the same information, so the quiz works with a screen reader.

License: Apache-2.0.

Original text. The pictures were drawn programmatically for this pack (flat shapes on a plain background, no text and no metadata): five PNG files and three lossless WebP files. No third-party assets.
